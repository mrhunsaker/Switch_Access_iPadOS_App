# Security Policy

## Supported versions
SwitchPlay is an early-stage prototype. Until a stable release is announced, security fixes are considered for the latest version on the default branch.

## Reporting a vulnerability
Do not report suspected vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's **Report a vulnerability** feature on the repository Security tab to submit a private report. Include a concise description, potential impact, affected files or commits, safe reproduction steps, and suggested mitigation where known.

Do not include real student, patient, or participant data. Use synthetic examples.

If private vulnerability reporting is not enabled, contact a repository maintainer privately through GitHub and request a secure reporting channel. Do not send credentials, secrets, or sensitive personal data through public channels.

## Response
Maintainers will acknowledge reports when reasonably possible, investigate, and coordinate a fix or mitigation. Please allow time for investigation before public disclosure. No response-time SLA is currently guaranteed.

## Data and privacy
Never commit API keys, signing credentials, provisioning profiles, private certificates, personal information, student records, health information, or participant recordings. Revoke and rotate any secret that is accidentally exposed, even if the commit is reverted.
